## Cohort and training protocol

The 159,571-row supplied source retains 159,564 eligible comments after the explicit
exclusion of seven normalized-empty texts. The 93 conflicting normalized-text
groups retain their original annotations together. The seed-42 grouped split has
111,731 training, 23,878 validation, and 23,955 internal-test rows. The feature is
comment text only; IDs and the derived `toxicity` target sum are excluded.

The model retains eight randomly initialized RoBERTa encoder layers, hidden size
512, eight attention heads, intermediate size 2,048, 51,484,678 parameters, and a
256-token input cap. Only the `roberta-base` tokenizer is pretrained. Training
uses training-only class weights, weighted BCE, AdamW learning rate 4e-5, weight
decay 0.01, cosine schedule, 10% warmup, patience three, and CUDA float16 AMP.

The efficient profile caches tokenization, dynamically pads each microbatch,
uses zero workers and two CPU threads, and leaves gradient checkpointing off.
Synthetic full-length probes selected microbatch 64 with accumulation four,
preserving nominal effective batch 256. Partial accumulation groups use actual
sample counts. The changed padding/microbatch execution defines a new numerical
experiment; the historical 80/20 neural output has not been reproduced.

## Reproduce the evidence checks

From the repository root with the core dependencies installed, check public
aggregate arithmetic, metric/threshold consistency, plotted data series, and
file hashes without the private inputs:

```bash
python scripts/verify_colab_results.py verify-public --report-dir reports/colab_efficient_v1
```

This check reports that the original private numerical audit is not repeated.
It does not load a model or produce neural predictions. To additionally rerender
and compare exact PNG pixels, install `requirements-notebooks.txt` and append
`--check-plots`. That optional check requires the original Matplotlib and font
environment; the default data-series and checksum checks are the portable path.

The full private audit can be repeated only with the authorized original source,
returned private ZIP, and saved CPU baseline run. Install
`requirements-notebooks.txt` for plot generation, then replace these placeholder
input paths with local files and choose an output directory that does not exist:

```bash
python scripts/verify_colab_results.py import \
  --review /path/to/results_for_review.zip \
  --private-verification /path/to/verification_private.zip \
  --calibration /path/to/calibration.json \
  --source /path/to/train_preprocessed.csv \
  --baseline-run /path/to/frozen-baseline-run \
  --challenge-test /path/to/test_preprocessed.csv \
  --output-dir runs/returned-review-audit
```

The import performs bounded numerical/source checks and creates a new aggregate
report directory; it does not deserialize models, extract private arrays to disk,
train, or run inference. `--baseline-run` supplies the saved validation evidence
needed for the same-validation comparison. `--challenge-test` checks its unlabeled
status without scoring it. Preserve the original returned files and existing
report directory when reproducing the review.
