# Historical source archive

These notebooks are sanitized source derivatives of the three supplied notebooks:

- [model_FINAL_Report_historical.ipynb](notebooks/model_FINAL_Report_historical.ipynb): selected implementation reference.
- [modelXXXX_historical.ipynb](notebooks/modelXXXX_historical.ipynb): matching five-epoch historical variant.
- [Untitled10_historical.ipynb](notebooks/Untitled10_historical.ipynb): learning-rate/warmup/epoch variant.

They preserve historical code for review, including the documented checkpoint/export/report mismatch. All cell outputs are cleared and execution counts are null. Illustrative comment examples and demonstration predictions have been omitted. These files are not clean executable project entry points; use the repaired CLI and current notebooks.

The original uploads remain unchanged outside the publication tree. Their hashes are in [source_manifest.json](../docs/source_manifest.json). The two original PDF uploads are byte-identical; the report and its contact details are not redistributed here.

Aggregate metrics extracted from original saved outputs are retained separately in [historical_metrics.json](../reports/historical_metrics.json). They are historical validation evidence, not results rerun from these cleared archives. The [notebook audit](../docs/notebook_audit.md) explains the source cells and limitations; the [corrected report](../reports/corrected_report.md) is the evidence-bounded narrative derivative.
